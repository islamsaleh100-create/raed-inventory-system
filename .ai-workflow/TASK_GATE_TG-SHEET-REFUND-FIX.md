# المسار (أ) — `refundCash` موجود في النسخة المنشورة

الباج حيّ. أَصلِحه في كود Phase 2 حيث يوجد.

### الموضعان — كلاهما، لا أحدهما

في `Validation.gs` كما هو على فرع الأمان (أرقام الأسطر من `git show`):

```javascript
// سطر 67
var refundCash = normalized.refund_bill === '' ? 0 : normalized.refund_bill;

// سطر 69 — فحص حد العهدة
? Math.round((normalized.cash_sales - normalized.cash_expense - refundCash) * 100) / 100 : null;

// سطر 76 — الكاش المتوقع
var expectedCashDeposited = cashReady ? Math.round((normalized.cash_sales
    - normalized.cash_expense - normalized.cash_float_carried_forward - refundCash) * 100) / 100 : null;
```

**المطلوب:** احذف `- refundCash` من **السطرين ٦٩ و ٧٦**، واحذف تعريف `refundCash` (سطر ٦٧) إن لم
يبقَ له استخدام. أضف تعليقًا:

```javascript
// أرقام نقطة البيع تصل صافية بعد المرتجعات (قرار المالك 2026-08-14 من الكاشير).
// طرح refund_bill هنا خصم مزدوج يولّد عجزًا وهميًا بقيمة المرتجع.
// refund_bill يبقى مُدخلًا ومحفوظًا — للتقرير فقط.
```

**لا تحذف حقل `refund_bill`** من `REQUIRED_COLUMNS` ولا من الشيت. التغيير في المعادلة فقط.
