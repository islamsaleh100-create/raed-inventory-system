## System Overview (placeholder)

Raed Inventory is a supply chain system for an F&B group with 4 brands:
Onda (bakery), Ronaldos (pizza), Shawarma, Griddle (grills).
25 branches across Riyadh and Dammam, 2 warehouses, 2 central kitchens.

## Workflow (placeholder)

Branch User creates a request → Area Manager approves → Auto-split to
Warehouse and/or Kitchen → Production / Picking → Delivery.
